LESSON 5: Giving Clear Instructions and Checking Understanding

A. LESSON OVERVIEW

Lesson Number & Title: Lesson 5: Giving Clear Instructions and Checking Understanding

Allocated Learning Duration: 120 Minutes (2.0 Hours)

Occupational Relevance: In multinational IT helpdesks and shared service centers in Malaysia (e.g., BASF JA010, iFAST Global Hub JA012, Swarovski JA025, Midea JA007, BE International JA011), frontline specialists frequently guide users through multi-step technical procedures. Common tasks include configuring VPN clients, setting up Multi-Factor Authentication (MFA), adjusting email security settings, and navigating self-service portals. Frontline agents must deliver clear, sequential instructions using imperative verbs and transition markers, while constantly verifying user comprehension at each step to prevent user errors and abandoned support calls.

Measurable Learning Objectives:By the end of this 120-minute lesson, Thai IT undergraduate learners will be able to:

Apply imperative verbs (click, select, enter, toggle, verify) paired with sequential transition markers (first, next, subsequently, once that is done, finally) to structure multi-step technical guidance.

Construct polite comprehension-check questions ("Does that dialog box appear on your screen?", "Have you located the 'Settings' tab?") to verify user alignment before moving to the next step.

Re-order and refine scrambled or ambiguous technical instructions into clear, logical, step-by-step user guides.

Perform a 60-second instructional spoken response in a simulated technical support call guiding a user through a Multi-Factor Authentication (MFA) setup or VPN configuration, achieving a minimum score of "3" across all rubric criteria.

LESSON 5 COMMUNICATION FUNCTIONS, VOCABULARY, AND GRAMMAR MATRIX

========================================================================================

Target Communication Functions:

  - Delivering clear, step-by-step technical instructions and device configurations

  - Sequencing technical tasks logically using sequential transition markers

  - Verifying customer comprehension and visual alignment at every step

  - Pausing and confirming task completion before advancing to subsequent steps

B. ATTENTION-GRABBING OPENING HOOK

Workplace Context: Corporate IT Helpdesk at a Shared Service Center in Kuala Lumpur, Malaysia.

The Problem / Communication Mistake: An IT support agent named Ken is guiding a remote employee through setting up Multi-Factor Authentication (MFA). Ken dumps four steps in one single, rapid-fire sentence: "Go to settings click security generate token type the 6-digit code and press enter." The user gets completely confused, types the code into the wrong field, locks herself out of her account, and panics ("Wait! What screen are you talking about? My app is locked now!").

Reflective Question for Students:

Why did Ken's rapid-fire instruction cause the user to lock her account?

How can you break down a complex multi-step technical process into bite-sized instructions with clear checks?

Occupational Importance: In Malaysian enterprise helpdesks, user lockout incidents caused by poor agent instructions increase ticket resolution costs and generate avoidable escalation tickets. Delivering one instruction at a time and checking for visual confirmation ensures high First Contact Resolution (FCR) rates.

D. EXPLICIT TEACHING OF SENTENCE STRUCTURES AND LANGUAGE USE

1. Language Pattern 1: Imperative Actions & Sequential Transition Markers

========================================================================================

LANGUAGE PATTERN 1: IMPERATIVES & SEQUENTIAL TRANSITION MARKERS

========================================================================================

Form / Syntax Pattern:

  [Sequential Marker: First / Next / Subsequently / Once that is done / Finally] + 

  [Imperative Action Verb: Click / Select / Enter / Toggle / Verify] + [Target Field/Button]



Communicative Function:

  Guiding users through complex technical configurations in a clear, logical, step-by-step chronological order.



Explanation in Thai (คำอธิบายภาษาไทย):

  การให้คำแนะนำขั้นตอนทางเทคนิค (Step-by-step instructions) ต้องเริ่มประโยคด้วยคำบอกลำดับขั้นตอน (Sequential Markers) เช่น "First", "Next", "Subsequently", "Once that is done", "Finally" ตามด้วยกริยาคำสั่ง (Imperative Verb) ขึ้นต้นประโยคโดยไม่ต้องใส่ประธาน เช่น "Click...", "Select...", "Enter..." เพื่อความกระชับและชัดเจน



Contextualized Workplace Examples:

  Example 1: "First, click on the 'Account Settings' tab located at the top right of your portal."

  Example 2: "Next, select 'Multi-Factor Authentication' from the drop-down menu."

  Example 3: "Once that is done, enter the 6-digit security code generated by your mobile app."

  Example 4: "Finally, click 'Save Changes' to finalize your security updates."



Common Learner Errors & Corrections:

  x Incorrect: "You must to click security and then you type password." (Clunky syntax with 'must to')

    ✓ Correct: "First, click 'Security Settings', and then enter your current password."

  x Incorrect: "First step click here, second step click there, third step finish." (Repetitive, non-standard)

    ✓ Correct: "First, click 'Account'. Next, select 'Privacy'. Finally, click 'Confirm'."

========================================================================================

Substitution / Transformation Exercise (10 Minutes)

Instructions: Rewrite the following informal instructions into formal, sequentially marked step-by-step guides.

Informal: "Open your browser and clear cache then restart."

Professional Transformation: "First, open your web browser. Next, clear your browsing cache. Once that is done, restart the application."

Informal: "Type your email and press submit button."

Professional Transformation: "First, enter your registered email address into the input field. Next, click the 'Submit' button."

Informal: "Download setup file and run it."

Professional Transformation: "First, download the installation package. Subsequently, double-click the setup file to launch the installer."

Production Task (10 Minutes)

Write a 3-step sequential instruction using First, Next, and Finally to guide a user through updating their corporate Wi-Fi password on a smartphone.

Student Output Example: "First, open your phone's 'Settings' menu. Next, select 'Wi-Fi' and choose your corporate network. Finally, enter your new password and tap 'Connect'."

2. Language Pattern 2: Visual Comprehension-Check Questions

========================================================================================

LANGUAGE PATTERN 2: VISUAL COMPREHENSION-CHECK QUESTIONS

========================================================================================

Form / Syntax Pattern:

  Do you see + [Visual Screen Element]?

  OR: Does + [Visual Screen Element] + [appear / display] + on your screen?

  OR: Have you located + [Specific Icon / Tab]?



Communicative Function:

  Verifying that the customer is viewing the correct interface, menu, or dialog box before proceeding to the next step.



Explanation in Thai (คำอธิบายภาษาไทย):

  หลีกเลี่ยงการถามว่า "Do you understand?" (คุณเข้าใจไหม?) เพราะลูกค้ามักจะตอบว่า "เข้าใจ" แม้ว่าจะกำลังสับสน ประโยคเช็กความเข้าใจที่มีประสิทธิภาพในงาน Tech Support ต้องเป็นการเช็กสิ่งที่ปรากฏบนหน้าจอจริง (Visual Checks) เช่น "Do you see the blue 'Submit' button?" หรือ "Does a confirmation prompt appear on your screen?"



Contextualized Workplace Examples:

  Example 1: "Does the green 'Connected' icon appear at the bottom of your screen?"

  Example 2: "Do you see the 6-digit verification box on your display?"

  Example 3: "Have you located the 'Network Adapter' tab in your control panel?"



Common Learner Errors & Corrections:

  x Incorrect: "You understand or not?" (Informal, rude, and culturally inappropriate)

    ✓ Correct: "Does the configuration window appear on your screen now?"

  x Incorrect: "Is it okay?" (Vague check that does not confirm visual alignment)

    ✓ Correct: "Do you see the blue 'Save Settings' button at the bottom right?"

E. GUIDED EXAMPLES AND MODEL DIALOGUES

Model Dialogue 5.1: Multi-Step Multi-Factor Authentication (MFA) Setup

Workplace Context: IT Helpdesk at BASF (Malaysia) Sdn. Bhd. (JA010).

Interaction Type: Inbound Call — Assisting an Employee with MFA Mobile Enrollment.

========================================================================================

MODEL DIALOGUE 5.1: SEQUENTIAL INSTRUCTIONAL GUIDANCE

========================================================================================

Agent (Mei):     "I would be glad to guide you through setting up your MFA security token, Mr. David. Let's complete this step-by-step together."

                  [Communication Purpose: Lesson 1 Opening & Transition to Step-by-Step Guidance]



Caller (Mr. David): "Great, thank you! I have my smartphone ready next to my laptop."



Agent (Mei):     "Perfect. First, please open your laptop browser and navigate to '[suspicious link removed]'. Let me know once the login portal loads."

                  [Communication Purpose: Step 1 - Sequential Marker, Imperative Action & Pause Prompt]



Caller (Mr. David): [Pause 3 seconds] "Okay, the BASF security portal is open now."



Agent (Mei):     "Excellent. Next, click the blue button that says 'Register New Device'. Does a QR code display on your laptop screen?"

                  [Communication Purpose: Step 2 - Sequential Marker, Imperative & Visual Check]



Caller (Mr. David): "Yes, I see a black and white QR code in the center of the page."



Agent (Mei):     "Wonderful. Subsequently, open the Authenticator application on your smartphone and tap 'Scan QR Code'."

                  [Communication Purpose: Step 3 - Transition Marker & Imperative Action]



Caller (Mr. David): "Done! My phone just generated a 6-digit passkey."



Agent (Mei):     "Finally, enter that 6-digit passkey into the prompt box on your laptop and click 'Verify'. Does a green checkmark appear?"

                  [Communication Purpose: Final Step - Sequential Marker, Imperative & Final Visual Check]



Caller (Mr. David): "Yes! It says 'Authentication Successful'!"



Agent (Mei):     "Fantastic! Your MFA setup is now complete and your account is secure."

                  [Communication Purpose: Success Confirmation & Closure]



========================================================================================

ANALYSIS & FORMALITY OPTIONS:

Why This Dialogue is Effective:

  1. Agent Mei delivers exactly ONE action per step, preventing user cognitive overload.

  2. Uses explicit transition markers (*First, Next, Subsequently, Finally*).

  3. Uses specific visual checks (*"Does a QR code display...?", "Does a green checkmark appear...?"*).



Formality Variations:

  - Standard Professional: "First, please navigate to the portal page."

  - Executive/VIP Line: "When you are ready, kindly select the 'Security Overview' tab at your convenience."

Activity 5.1: Knowledge Check & Instruction Identification (15 Minutes)

An agent wants to verify if a caller is looking at the correct settings page. Which question is most effective?

A) "You understand what I said?"

B) "Does the 'Network Properties' dialog box appear on your display?"

C) "Why haven't you clicked the button yet?"

D) "Are you smart enough to find the button?"

Answer: B

Explanation: Option B uses a specific visual check ("Does the 'Network Properties' dialog box appear...?") to verify screen alignment.

Which sequence of transition markers represents the most professional chronological order?

A) First -> Subsequently -> Next -> End

B) First -> Next -> Once that is done -> Finally

C) Then -> First -> After that -> Okay

D) One -> Two -> Three -> Four

Answer: B

Explanation: Option B follows standard professional transition sequencing (First -> Next -> Once that is done -> Finally).

Complete the sentence: "_____ that is completed, enter your new corporate password into the box."

A) Once

B) If

C) Why

D) Where

Answer: A

Explanation: "Once that is completed..." is a standard transition phrase indicating that the previous step must be finished before proceeding.
