# TECHQUEST Lesson Slides Directory

This directory stores presentation slides for all 8 EOP learning modules.

## Folder Structure
```
client/public/slides/
├── lesson1/    (Lesson 1: Responding to Customer Enquiries)
├── lesson2/    (Lesson 2: Identifying & Clarifying Technical Problems)
├── lesson3/    (Lesson 3: Explaining Troubleshooting Procedures)
├── lesson4/    (Lesson 4: Handling Customer Complaints & Empathy)
├── lesson5/    (Lesson 5: Providing Clear Step-by-Step Instructions)
├── lesson6/    (Lesson 6: Escalating Unresolved Cases & SLAs)
├── lesson7/    (Lesson 7: CRM Ticket Hygiene & Documentation)
├── lesson8/    (Lesson 8: Support Shift Handover & Case Summaries)
└── README.md
```

## How to Add Your Slides:
You can provide slides in any of the following formats:

### Option A: Slide Images (Recommended for browser presentation)
Export your PowerPoint or Canva slides as PNG or JPG images, and place them inside the corresponding lesson folder named sequentially:
- `slide_1.png` (Slide 1)
- `slide_2.png` (Slide 2)
- `slide_3.png` (Slide 3)
- `slide_4.png` (Slide 4)
- `slide_5.png` (Slide 5)

*(The platform slide viewer will automatically detect and display these images.)*

### Option B: Standalone Presentation File (PDF / PPTX)
Save your slide deck in the folder as:
- `slides.pdf` or `presentation.pdf`

*(Students and instructors will be able to view and download it directly from the lesson viewer.)*

---
*Note: If no custom slide files are placed in a lesson folder yet, the platform automatically renders interactive pedagogical placeholder slides with the lesson's target objectives, model dialogue, language functions, and vocabulary.*
